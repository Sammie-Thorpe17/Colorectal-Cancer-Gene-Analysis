# Colorectal-Cancer-Gene-Analysis
The data used in this study were gene expression samples which were in a tabular format. This meant that the aim for this project was to optimise, interpret and compare a Support Vector Machine (SVM) and Random Forest (RF) model on their ability to classify CRC patient samples by binary TNM stage.
To gather the CRC samples, the data for this study was retrieved from the (https://xenabrowser.net/datapages/) TCGA database on 15/06/2026.
Therefore, the sublink from the (https://xenabrowser.net/datapages/) database that was used for this study was titled 'GDC TCGA Colon Cancer (COAD)', where the files 'RNAseq STAR Counts' and 'Phenotypes' were downloaded into RStudio. The 'Phenotypes' data was downloaded to retrieve the CRC TNM stages of each patient sample.
